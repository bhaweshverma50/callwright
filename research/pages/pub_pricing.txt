02 · HOW PRICING WORKS
Five components, one bill.

Every call is priced from the same five components. Each one is quoted as a per-minute rate. Your bill is the call duration multiplied across all of them — rounded up to the nearest second.

Speech-to-text (STT)

Transcribes the caller's voice in real time. Billed strictly per minute of call duration — no usage cap, no surcharge.

NEVER SURCHARGES

Large language model (LLM)

The reasoning brain that decides what your agent says next. Billed per minute, with a generous token bundle included. Surcharges only kick in if a call uses far more tokens than a typical conversation of that length.

CAN SURCHARGE

Text-to-speech (TTS)

Renders the agent's reply into a natural voice. Billed per minute with a character bundle included. Surcharges apply only on unusually verbose calls that exceed the bundle.

CAN SURCHARGE

Noise cancellation (NC)

Optional. Cleans up background noise on incoming audio. Billed per minute of call duration. Never surcharges.

NEVER SURCHARGES

Platform fee

Covers orchestration, telephony, analytics and the dashboard. Flat per-minute fee. Never surcharges.

NEVER SURCHARGES

Call duration is rounded up to the nearest whole second before any math, so a 4.2-second hang-up bills as 5 seconds — never less.

03 · SURCHARGE PRICING
When the bundle isn't enough.

The per-minute prices already include a generous bundle of usage — enough for a normal voice conversation. A surcharge only kicks in when a single call uses dramatically more LLM tokens or TTS characters than its duration would suggest.

COMPONENT

BUNDLE PER MINUTE

WHAT TRIGGERS A SURCHARGE

LLM input tokens

20,000 tokens / min

Calls that send long system prompts, large knowledge-base context, or repeated tool results.

LLM output tokens

200 tokens / min

Agents that generate unusually long responses for the call duration.

TTS characters

750 characters / min

Calls where the agent talks far more than usual relative to call length.

THE RULE

Each surchargeable component is billed on whichever of these is bigger:

ratio = max(
  duration_in_minutes,
  usage / bundle_per_minute
)
cost = rate_per_min × ratio

If usage stays within the bundle, the duration wins and the bill is just rate × minutes — no surcharge. If usage spills over, the bundle ratio wins and you pay for the overage at the same per-minute rate.

WHAT YOU'LL SEE IN YOUR BILL

For any call where a surcharge applied, the call detail panel shows two extra numbers next to the affected component:

Surcharge amount — the dollar value added on top of the base duration price. Calculated as rate × (ratio − duration_in_minutes).
Bundle multiplier — how many times over the bundle you went, e.g. 1.13× means usage was 13% above what the duration alone would cover.

WHY LLM SURCHARGED

Input tokens used: 102,348. Bundle for this duration was 20,000 × 4.5167 ≈ 90,334. Going 13% over the bundle pushes the LLM ratio up to 5.1174 min. Surcharge = 0.0015 × (5.1174 − 4.5167) ≈ $0.0009.

WHY TTS DID NOT

Characters used: 2,555. Bundle for this duration was 750 × 4.5167 ≈ 3,388. Usage stayed inside the bundle, so the duration ratio wins and TTS bills as a flat 4.5167 minutes — no surcharge.

Most calls never surcharge

You can see them per call
